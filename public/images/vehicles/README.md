# Vehicle Images Directory

This directory stores all vehicle images for the AUTO ANI website.

## Image Naming Convention

Each vehicle should have images named according to its slug:

### Main Image
`{slug}-main.jpg`
Example: `mercedes-benz-e-class-2023-main.jpg`

### Gallery Images
`{slug}-{number}.jpg`
Examples:
- `mercedes-benz-e-class-2023-1.jpg`
- `mercedes-benz-e-class-2023-2.jpg`
- `mercedes-benz-e-class-2023-3.jpg`

## Image Specifications

### Recommended Sizes
- **Main Image**: 1200x800px (landscape)
- **Gallery Images**: 1200x800px (landscape)
- **Thumbnails**: Auto-generated by Next.js Image component

### File Format
- Use `.jpg` or `.jpeg` for photos
- Use `.webp` for better compression (optional)
- Keep file sizes under 500KB per image

### Quality Guidelines
- High resolution (at least 1200px wide)
- Good lighting, professional quality
- Show different angles (exterior, interior, details)
- Consistent style across all vehicles

## Adding Images for New Vehicles

When adding a new vehicle via the script:
```bash
node scripts/manage-vehicles.js add
```

The script will tell you which image files to add. Follow the naming convention above.

## Image Optimization (Optional)

For better performance, optimize images before uploading:

### Using ImageMagick:
```bash
# Resize and optimize
convert original.jpg -resize 1200x800 -quality 85 optimized.jpg
```

### Using Sharp (Node.js):
```javascript
const sharp = require('sharp');

sharp('original.jpg')
  .resize(1200, 800)
  .jpeg({ quality: 85 })
  .toFile('optimized.jpg');
```
